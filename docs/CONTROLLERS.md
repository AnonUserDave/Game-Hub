# Controller status

Current implementation and evidence are maintained in [CONTROLLER.md](CONTROLLER.md).

Initial discovery found the XB1 Fusion Pro over USB but no Apple GameController profile. The project now includes an original exact-model user-space USB backend. The user exercised A/B/X/Y, triggers and sticks in the integrated app and reported working input. Other controls, each game action, focus transitions and hot unplug/replug remain separate verification work.
